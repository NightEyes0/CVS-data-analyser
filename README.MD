# CSV Data Analyser 

A Python-based data analysis tool that processes, cleans, and visualizes local crime data.

# Overview
This project demonstrates how to ingest raw CSV data,even in the case handle missing/corrupted values, and extract real-world insights. 

The script automatically reads the data, calculates the most frequent crime types, and outputs a visual bar chart.

# Technologies Used
* Python 3
* Pandas (Data cleaning/manipulation)
* Matplotlib (Data visualization/charts)
